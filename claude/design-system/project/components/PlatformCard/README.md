# Cartão de plataforma

Para apresentar uma plataforma de IA, um parceiro ou um produto: o que é, como se organiza e quando a A-Players indica.

## Variações e classes

- **Plataforma**: `.ap-plate.ap-front`. A classe mantém o nome `ap-front`.

## O que você fornece

A folha da marca (`components/bundle.css`, a `css/aplayers.css` oficial) e o tom de cada item em `--ap-tone` (padrão `--ap-blue`). Copie a marcação da prévia e troque apenas o texto e o tom. Referência completa: https://aplayers-site-final.netlify.app/design-system/#componentes/plataforma.
