# Links

Sublinhado de 2px no tom, afastado do texto; no hover ele sobe para perto. Para chamadas no fim de cartões e portas.

## Variações e classes

- **Link de texto**: `.ap-link`

## O que você fornece

A folha da marca (`components/bundle.css`, a `css/aplayers.css` oficial) e o tom de cada item em `--ap-tone` (padrão `--ap-blue`). Copie a marcação da prévia e troque apenas o texto e o tom. Referência completa: https://aplayers-site-final.netlify.app/design-system/#componentes/links.
