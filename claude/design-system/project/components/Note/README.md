# Notas

Caixas no tom para o que a A-Players indica, entrega ou garante. O fundo mistura 11% do tom com o cartão.

## Variações e classes

- **Notas**: `.ap-note · .ap-fit`

## O que você fornece

A folha da marca (`components/bundle.css`, a `css/aplayers.css` oficial) e o tom de cada item em `--ap-tone` (padrão `--ap-blue`). Copie a marcação da prévia e troque apenas o texto e o tom. Referência completa: https://aplayers-site-final.netlify.app/design-system/#componentes/notas.
