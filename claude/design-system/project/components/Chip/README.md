# Chips

Aplicações e produtos com o ícone oficial, ou etiquetas curtas. Quatro variações para fundos e pesos diferentes.

## Variações e classes

- **Chips**: `.ap-chip · --soft · --tone · --marked`

## O que você fornece

A folha da marca (`components/bundle.css`, a `css/aplayers.css` oficial) e o tom de cada item em `--ap-tone` (padrão `--ap-blue`). Copie a marcação da prévia e troque apenas o texto e o tom. Referência completa: https://aplayers-site-final.netlify.app/design-system/#componentes/chips.
