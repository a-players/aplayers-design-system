# Pill

A etiqueta que abre uma página, com os quatro triângulos da marca. Uma por abertura, em capitalização editorial.

## Variações e classes

- **Sobre a noite**: `.ap-pill`
- **Sobre a folha**: `.ap-pill--sheet`. Os triângulos usam o símbolo `#tris` (44 × 10).

## O que você fornece

A folha da marca (`components/bundle.css`, a `css/aplayers.css` oficial) e o tom de cada item em `--ap-tone` (padrão `--ap-blue`). Copie a marcação da prévia e troque apenas o texto e o tom. Referência completa: https://aplayers-site-final.netlify.app/design-system/#componentes/pill.
