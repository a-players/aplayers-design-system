# Listas

Seis formas de listar, cada uma para um tipo de conteúdo: tópicos, pontos, passos, fluxo, jornada e etapas.

## Variações e classes

- **Tópicos, pontos e passos**: `.ap-bars · .ap-ticks · .ap-steps`
- **Fluxo com pulso**: `.ap-flow · --n`
- **Jornada e etapas**: `.ap-acts · .ap-stepline`

## O que você fornece

A folha da marca (`components/bundle.css`, a `css/aplayers.css` oficial) e o tom de cada item em `--ap-tone` (padrão `--ap-blue`). Copie a marcação da prévia e troque apenas o texto e o tom. Referência completa: https://aplayers-site-final.netlify.app/design-system/#componentes/listas.
