# Parceiros

Logos oficiais das parceiras estratégicas, sempre na ordem Atlassian, CISP1, monday.com, com a mesma altura óptica (Atlassian 23px, CISP1 46px, monday.com 28px numa placa de 68 x 280px). As Collections da Atlassian usam o logo oficial, cada uma num quadro de 466 x 164; o par -dark é para o tema escuro.
